# FoodApp

A proposta da aplicação mobile é desenvolver um aplicativo voltado para restaurantes, inspirado em plataformas conhecidas como o iFood, com foco na exibição e descoberta de pratos culinários. A experiência é simples, rápida e pensada para atender tanto profissionais da área de alimentação quanto clientes interessados em conhecer novos pratos. A aplicação foi criada para a cadeira de mobile do curso de Analise e Desenvolvimento de Sistemas do IFPE - Campus Palmares.

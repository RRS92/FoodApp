# FoodApp

A proposta da aplicação mobile é desenvolver um aplicativo voltado para restaurantes, inspirado em plataformas conhecidas como o iFood, com foco na exibição e descoberta de pratos culinários. A experiência é simples, rápida e pensada para atender tanto profissionais da área de alimentação quanto clientes interessados em conhecer novos pratos. 

A API utilizada na aplicação para fazer as chamadas foi a 'TheMealDB' que é uma API gratuita que fornece um banco de dados de receitas culinárias do mundo todo, oferecendo informações detalhadas como nome do prato, imagem, instruções de preparo, ingredientes e categorias. Ideal para aplicativos de gastronomia, ela permite buscas por nome, letra inicial, ingredientes ou até receitas aleatórias, sendo amplamente usada por desenvolvedores para projetos educacionais, demonstrativos ou produtos voltados à culinária. 

*A aplicação foi criada para a cadeira de mobile do curso de Analise e Desenvolvimento de Sistemas do IFPE - Campus Palmares.*
